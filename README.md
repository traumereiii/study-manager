# 차곡 학습 관리 시안

`index.html`을 브라우저에서 열면 실행됩니다. 별도 설치나 서버는 필요하지 않습니다.

- **문제집**: 목록의 `문제집 만들기`에서 이름과 소개를 입력합니다. 빈 문제집에는 첫 문제를 추가할 수 있습니다.
- **문제**: 문제집 상세의 `문제 만들기`에서 질문형, 빈칸형, 선다형 카드를 만듭니다.
- **설정**: 단축키, 매일 학습 알람, 문제당 제한시간을 변경하고 저장합니다. 기본 단축키는 정답 확인 `Space`, 몰라요 `1`, 알아요 `2`입니다.
- **제한시간**: 0초는 무제한입니다. 시간이 끝나면 정답이 표시되고, 기억 여부는 직접 평가합니다.
- **알람**: 기기 현지 시각 기준, 지정 시각 이후 하루 한 번 앱 안에 알림을 표시합니다. 앱이 열려 있어야 하며 백그라운드 탭에서는 지연될 수 있습니다. 운영체제 알림이나 앱 종료 후 알림은 지원하지 않습니다.
- **통계**: 오늘 및 누적 평가 횟수, 알아요 비율, 학습한 날 수, 최근 7일 추이, 문제집별 현황을 표시합니다. 같은 문제의 반복 평가도 각각 집계합니다. 통계 기능 추가 전의 학습 기록은 소급 생성하지 않습니다.

데이터는 현재 브라우저의 로컬 저장소에 보관합니다. 기기 간 동기화는 없으며 브라우저 데이터를 삭제하면 기록도 사라집니다. 기존 예시 카드와 저장된 문제는 유지됩니다.

## 검증

Node.js가 설치되어 있으면 `node verify.cjs`로 생성, 저장·복원, 입력 검사, 제한시간, 통계, 알람, 저장 실패 처리를 검증할 수 있습니다. 이 검증은 브라우저 화면을 직접 검사하는 테스트는 아닙니다.
