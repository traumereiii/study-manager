# 차곡 학습 관리 시안

`prototype/index.html`을 브라우저에서 열면 실행됩니다. 별도 설치나 서버는 필요하지 않습니다.

- **문제집**: 목록의 `문제집 만들기`에서 이름과 소개를 입력합니다. 빈 문제집에는 첫 문제를 추가할 수 있습니다.
- **문제집 수정**: 상세의 `문제집 수정`에서 제목과 한 줄 소개를 수정합니다. 상세의 레벨 행을 누르면 해당 레벨의 카드만 볼 수 있습니다.
- **문제**: 문제집 상세의 `문제 만들기`에서 질문형, 빈칸형, 선다형 카드를 만듭니다.
- **문제 관리**: 문제집 상세의 `문제 관리`에서 등록된 문제와 정답·해설을 확인하고 수정·삭제할 수 있습니다. 예시 문제도 관리할 수 있으며 삭제 전 확인을 요청합니다.
- **검색·페이지 이동**: 문제 관리에서 질문·정답·해설·보기를 검색하고 레벨을 필터링합니다. 페이지당 10장을 표시하며 검색 조건은 새로고침 후에도 유지됩니다.
- **학습 중 수정**: 학습 화면의 `문제 수정`으로 현재 문제를 수정합니다. 편집 중 타이머는 멈추며 취소하면 이어서 학습하고, 저장하면 같은 문제를 새 제한시간으로 다시 표시합니다.
- **암기 레벨 초기화**: 문제 관리와 학습 화면에서 해당 문제만 Level 1로 되돌립니다. 기존 학습 통계는 유지됩니다.
- **설정**: 단축키, 매일 학습 알람, 문제당 제한시간을 변경하고 저장합니다. 기본 단축키는 정답 확인 `Space`, 몰라요 `1`, 알아요 `2`입니다.
- **제한시간**: 0초는 무제한입니다. 시간이 끝나면 정답이 표시되고, 기억 여부는 직접 평가합니다.
- **알람**: 기기 현지 시각 기준, 지정 시각 이후 하루 한 번 앱 안에 알림을 표시합니다. 앱이 열려 있어야 하며 백그라운드 탭에서는 지연될 수 있습니다. 운영체제 알림이나 앱 종료 후 알림은 지원하지 않습니다.
- **통계**: 오늘 및 누적 평가 횟수, 알아요 비율, 학습한 날 수, 최근 7일 추이, 문제집별 현황을 표시합니다. 같은 문제의 반복 평가도 각각 집계합니다. 통계 기능 추가 전의 학습 기록은 소급 생성하지 않습니다.

데이터는 현재 브라우저의 로컬 저장소에 보관합니다. 기기 간 동기화는 없으며 브라우저 데이터를 삭제하면 기록도 사라집니다. 기존 예시 카드와 저장된 문제는 유지됩니다.

## 검증

Node.js가 설치되어 있으면 `prototype` 디렉터리에서 `node verify.cjs`로 생성, 수정·삭제, 레벨 초기화, 이전 저장 데이터 호환, 입력 검사, 제한시간, 통계, 알람, 저장 실패 처리를 검증할 수 있습니다. 이 검증은 브라우저 화면을 직접 검사하는 테스트는 아닙니다.

## 프런트엔드

`frontend/`는 프로토타입을 Vue 3·TypeScript·Vite로 옮긴 화면입니다. 로그인 화면이 있고, 모킹 API(`npm run dev`) 또는 백엔드 서버(`npm run dev:server`)로 실행할 수 있습니다. 실행 방법은 [프런트엔드 README](frontend/README.md)를 참고하세요.

## 서버

`backend/`는 Kotlin·Spring Boot, JDK 25, Gradle 9.8.1, MySQL 8·JPA 기반 서버입니다. 고정 관리자 계정과 JWT 로그인·재발급·로그아웃을 제공합니다. 실행 및 API 사용 방법은 [서버 README](backend/README.md), 요구사항은 [서버 PRD](docs/SERVER_PRD.md)를 참고하세요. 프런트엔드는 `npm run dev:server`로 이 서버와 연동합니다.
