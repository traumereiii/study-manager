# 리디자인 자료

`frontend/` UI를 다시 설계하기 위해 모은 조사 자료와 시안입니다. 2026-10-26에 작성했습니다.

## 방향

- Mochi처럼 무채색 바탕에 단순한 구성을 사용합니다. 참고 순위는 Mochi, Anki, RemNote 순입니다.
- 감성 문구(격려 문구, 영문 보조 표제, 히어로 배너)는 넣지 않습니다.
- 정보 구조(사이트맵)를 먼저 다시 설계하고, 그 위에 화면을 만듭니다.

기존 `DESIGN.md`는 따뜻한 회백색·녹색 강조와 격려 문구를 원칙으로 두고 있어 이 방향과 맞지 않습니다. 시안이 확정되면 `DESIGN.md`를 새 기준으로 갱신합니다.

## 현재 화면에서 고칠 점

| 문제 | 내용 |
| --- | --- |
| 같은 안내가 여러 번 반복됨 | 사이드바, 브레드크럼, `← 뒤로` 링크, 영문 보조 표제, 한국어 부제가 한 화면에 모두 있어 실제 콘텐츠가 아래로 밀립니다. |
| 전체가 흐릿함 | 모든 요소가 비슷한 연녹색이고, 보조 글자색 `#858d85`는 배경 대비가 3.17:1로 4.5:1 기준에 못 미칩니다. |
| 학습 화면에 집중하기 어려움 | 학습 중에도 사이드바와 상단바가 남아 있고, 정답 확인 전부터 관리 버튼이 질문보다 눈에 띕니다. |
| 상세 화면 버튼이 많음 | 헤더에 같은 무게의 버튼 5개가 나란히 있습니다. |
| 레벨 구분이 약함 | 레벨 1~5 막대가 연녹색 농도 차이뿐입니다. |
| 학습까지 단계가 많음 | 목록에서 바로 학습을 시작할 수 없고 반드시 상세 화면을 거칩니다. |

## 사이트맵 (확정)

```
로그인            /login

앱 화면 (왼쪽 사이드바만, 상단바 없음)
├─ 홈             /                              오늘 학습할 문제집 표
├─ 문제집         /books/:id                     카드 목록 + 레벨 필터 + 검색 (기존 상세와 문제 관리를 합침)
│  ├─ 문제 만들기 /books/:id/cards/new
│  └─ 문제 편집   /books/:id/cards/:cardId       편집 + 미리보기 + 카드 레벨·학습 이력
├─ 통계           /stats
├─ 보관함         /archive
├─ 휴지통         /trash
└─ 설정           /settings                      학습·알림·계정

집중 화면 (사이드바 없음)
└─ 학습           /books/:id/study               카드 한 장 + 평가 버튼, 끝나면 결과 요약

모달
├─ 문제집 만들기 / 수정
├─ 카드 통계 (학습 중)
└─ 삭제 확인
```

| 지금 | 바뀐 후 |
| --- | --- |
| `/books` (카드 그리드 + 히어로) | `/` 홈 표. `/books`로 들어오면 `/`로 보냄 |
| `/books`의 보관함·삭제 탭 | `/archive`, `/trash` (사이드바 메뉴) |
| `/books/new`, `/books/:id/edit` 페이지 | 모달 |
| `/books/:id` 상세와 `/books/:id/manage` | `/books/:id` 한 화면 (`q`·`level`·`page` 쿼리 유지) |
| `/books/:id/cards/:cardId/edit`와 카드 통계 모달 | `/books/:id/cards/:cardId` 한 화면 (`?from=study` 흐름 유지) |
| 상단바(브레드크럼, 로그아웃) | 없앰. 로그아웃은 사이드바 계정 메뉴로 |
| 학습 중에도 보이는 사이드바·상단바 | 집중 화면으로 분리 |

서버 API는 바뀌지 않습니다. 전체 검색(`Ctrl K`)은 다음 단계에서 다룹니다.

## 참고 서비스

| 서비스 | 디자인 인상 | 가져올 점 |
| --- | --- | --- |
| Mochi | 무채색, 왼쪽 덱 목록 사이드바, 촘촘한 화면, 단축키 표시, `기억함/잊음` 두 가지 평가 | 무채색 바탕에 강조색 최소화, 사이드바에 문제집 직접 노출, 관리 행동은 `⋯` 메뉴로 |
| Anki | 학습 중에는 카드와 하단 버튼만 남김. 덱 목록 표에 오늘 복습 수 표시 | 학습 집중 화면, 홈의 오늘 학습 표 |
| RemNote | 흰 바탕에 보라·파랑 강조, 기능별 파스텔 카드 | 참고 정도 |
| Quizlet | 큰 카드 한 장, `Know / Still learning` 두 갈래 분류 | 두 갈래 평가 카운터 (Cloudflare 확인 화면 때문에 캡처하지 못함) |
| Brainscape | 1~5 자신감 평가와 레벨별 색상 | 레벨 단계를 확실히 구분 (캡처하지 못함) |
| Readwise | 따뜻한 크림색, 세리프 제목, 카드 한 장씩 보는 복습 | 카드 한 장 중심 복습 구성 |
| Knowt, 클래스카드 | 채도 높은 색, 큰 버튼, 캐릭터 | 반대 방향이라 참고만 |

앱 내부 화면은 대부분 로그인이 필요해서 랜딩 페이지의 제품 이미지를 기준으로 판단했습니다.

### 시안 사용법

- `chagok-redesign.html`을 브라우저로 열면 홈(오늘 학습 표)에서 시작합니다. 문제집 이름을 누르면 문제집 화면, `학습`을 누르면 학습 화면으로 이동합니다.
- 학습 화면 단축키: `Space` 정답 확인, `1` 몰라요, `2` 알아요, `Esc` 나가기. 문제집 화면에서 `/`를 누르면 검색창으로 이동합니다.
- 통계·설정·보관함·휴지통·문제 편집은 시안에 없으며, 누르면 안내 알림만 표시합니다.
- 데이터는 `frontend/src/api/mock/seed.ts`의 예시이며 새로고침하면 처음 상태로 돌아갑니다.
- 글꼴(IBM Plex Sans KR, IBM Plex Mono)은 Google Fonts에서 불러오므로 오프라인에서는 시스템 글꼴로 표시됩니다.
