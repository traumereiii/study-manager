# Study Manager MVP PRD

> 구현 현황 갱신일: 2026-10-15. 현재 제품명은 **차곡**이며, `prototype/`의 브라우저 프로토타입을 기준으로 작성했습니다. 3~11장은 초기 핵심 학습 흐름을 설명하고, 14장은 추가 기능과 실제 동작 및 제약을 기록합니다. 예시 수치는 실제 초기 데이터와 다를 수 있습니다.

## 1. 문서 개요

### 1.1 목적
개인 학습자가 문제집 단위로 학습 카드를 관리하고, 각 카드의 암기 상태를 확인하면서 반복 학습할 수 있는 최소 기능 제품(MVP)을 정의한다.

현재 PRD 범위는 아래 기능을 포함한다.

- 문제집 목록 조회
- 문제집 상세 조회
- 암기 레벨별 카드 현황 확인
- 학습 시작
- 문제 확인
- 정답 확인
- `몰라요` / `알아요` 평가
- 다음 문제로 이동
- 학습 완료 결과 확인
- 문제집 생성 및 문제 등록
- 문제집 제목·한 줄 소개 수정
- 등록된 문제 관리, 수정·삭제 및 개별 암기 레벨 초기화
- 단축키, 문제 제한시간, 앱 내 학습 알림 설정
- 학습 통계 확인
- 브라우저 로컬 저장 및 복원

노트, 문제집 삭제, 이미지 업로드, 계정 및 서버 동기화, 복잡한 복습 알고리즘은 현재 구현 범위에서 제외한다. 상세 구현 범위는 14장을 따른다.

---

## 2. 핵심 사용자 흐름

```text
문제집 목록
    ↓
문제집 상세
    ↓
학습하기
    ↓
문제 화면
    ↓
정답 확인
    ↓
몰라요 / 알아요
    ↓
다음 문제
```

정답 확인은 별도의 페이지로 이동하지 않고, 학습 화면 내부의 상태 전환으로 처리한다.

핵심 학습 흐름의 주요 화면은 다음 3개이다.

1. 문제집 목록
2. 문제집 상세
3. 학습 화면

현재 구현에는 문제집 만들기, 문제 만들기, 설정, 학습 통계 화면과 학습 완료 상태가 추가되어 있다. 화면 경로는 14.2절에 정리한다.

---

## 3. 화면 1 — 문제집 목록

### 3.1 목적
사용자가 자신이 보유한 문제집을 확인하고, 학습할 문제집을 선택한다.

### 3.2 표시 정보
각 문제집 카드 또는 목록 항목에는 다음 정보를 표시한다.

- 문제집 이름
- 전체 카드 수
- 오늘 학습 예정 카드 수
- 평균 암기 레벨
- 최근 학습일

### 3.3 예시

```text
문제집

[ Spring Security ]
전체 카드 120개
오늘 학습 18개
평균 암기 레벨 3.2
최근 학습 10/14

[ 회로이론 ]
전체 카드 85개
오늘 학습 12개
평균 암기 레벨 2.6
최근 학습 10/13
```

### 3.4 사용자 액션

#### 문제집 선택
문제집을 클릭하면 해당 문제집의 상세 화면으로 이동한다.

---

## 4. 화면 2 — 문제집 상세

### 4.1 목적
선택한 문제집의 전체 학습 상태와 암기 수준을 확인하고 학습을 시작한다.

### 4.2 표시 정보

- 문제집 이름
- 전체 카드 수
- 암기 레벨별 카드 수
- 학습하기 버튼

### 4.3 암기 레벨

카드는 암기 상태에 따라 레벨을 가진다.

예시:

```text
Level 1
Level 2
Level 3
Level 4
Level 5
```

레벨이 높을수록 사용자가 해당 내용을 더 잘 기억하고 있는 상태를 의미한다.

### 4.4 암기 현황 표시

예시:

```text
Spring Security

전체 카드
120개

암기 현황

Level 1   25개
Level 2   30개
Level 3   28개
Level 4   22개
Level 5   15개
```

시각적인 그래프 형태로 표시할 수도 있다.

```text
Lv.1  ████████████     25
Lv.2  ███████████████  30
Lv.3  ██████████████   28
Lv.4  ███████████      22
Lv.5  ███████          15
```

### 4.5 사용자 액션

#### 학습하기
`학습하기` 버튼을 누르면 해당 문제집의 학습 세션을 시작한다.

```text
[ 학습하기 ]
```

---

## 5. 화면 3 — 학습 화면

### 5.1 목적
문제를 한 장씩 확인하고, 사용자가 스스로 답을 생각한 뒤 정답을 확인하고 기억 여부를 평가한다.

### 5.2 기본 구성

- 문제집 이름
- 현재 문제 번호 / 전체 학습 문제 수
- 문제 내용
- 문제 이미지
- 정답 확인 버튼

예시:

```text
Spring Security

3 / 20

Q.

SecurityFilterChain의 역할은 무엇인가요?


[ 이미지 ]
(이미지가 있는 경우)


[ 정답 확인 ]
```

---

## 6. 문제 유형

학습 화면에서 문제는 다음 3가지 유형을 지원한다.

### 6.1 질문 & 답변형

사용자가 문제를 읽고 답을 머릿속으로 생각한 뒤 정답을 확인한다.

예시:

```text
Q.

JVM이란 무엇인가?


[ 정답 확인 ]
```

---

### 6.2 빈칸 채우기형

문장 일부를 빈칸으로 표시한다.

예시:

```text
TCP는 ______ 프로토콜이다.


[ 정답 확인 ]
```

사용자가 직접 입력할 수도 있지만, MVP에서는 반드시 입력을 강제하지 않아도 된다.

핵심은 먼저 답을 생각한 뒤 정답을 확인하는 것이다.

---

### 6.3 선다형

문제와 여러 개의 보기를 표시한다.

예시:

```text
다음 중 TCP의 특징은?

○ 비연결형
○ 연결지향형
○ 브로드캐스트
○ 단방향 통신


[ 정답 확인 ]
```

사용자가 보기를 선택할 수 있다.

정답 여부보다 사용자가 내용을 기억했는지를 최종적으로 `몰라요` / `알아요` 버튼으로 평가한다.

---

## 7. 문제 이미지

모든 문제 유형은 필요에 따라 이미지를 포함할 수 있다.

예시:

```text
Q.

다음 회로에서 출력 전압은?


[ 회로 이미지 ]


[ 정답 확인 ]
```

이미지는 문제 내용과 함께 노출한다.

MVP 범위에서는 이미지 첨부 방식이나 파일 관리 기능의 상세 구현은 정의하지 않는다.

---

## 8. 정답 확인 상태

### 8.1 동작
사용자가 `정답 확인` 버튼을 누르면 같은 학습 화면에서 정답 영역이 추가로 표시된다.

별도의 정답 페이지로 이동하지 않는다.

### 8.2 예시

정답 확인 전:

```text
Q.

SecurityFilterChain의 역할은 무엇인가요?


[ 정답 확인 ]
```

정답 확인 후:

```text
Q.

SecurityFilterChain의 역할은 무엇인가요?


정답

HTTP 요청에 적용될
보안 필터의 처리 순서를 정의한다.


해설

Spring Security의 여러 Filter가
SecurityFilterChain을 통해 순서대로 실행된다.


[ 몰라요 ]        [ 알아요 ]
```

---

## 9. 학습 평가

정답을 확인한 후 사용자는 자신의 기억 상태를 직접 평가한다.

버튼은 2개만 제공한다.

### 9.1 몰라요

```text
[ 몰라요 ]
```

의미:

- 내용을 기억하지 못했다.
- 현재 카드의 암기 수준이 낮다고 판단한다.
- 가까운 시일 내 다시 학습 대상이 된다.

### 9.2 알아요

```text
[ 알아요 ]
```

의미:

- 내용을 기억하고 있었다.
- 현재 카드의 암기 수준이 높아졌다고 판단한다.
- 다음 복습 간격을 늘릴 수 있다.

---

## 10. 문제 진행

사용자가 `몰라요` 또는 `알아요`를 선택하면 현재 문제의 학습 결과를 반영하고 다음 문제로 이동한다.

```text
문제 표시
   ↓
정답 확인
   ↓
몰라요 / 알아요
   ↓
다음 문제
```

학습 세션의 마지막 문제까지 완료하면 학습을 종료한다.

## 12. 이번 범위에서 제외하는 기능

다음 기능은 현재 프로토타입에 구현하지 않았다. 초기 제외 항목 중 문제집 생성, 문제 등록, 기본 통계와 앱 내 알림은 구현 범위로 편입했다.

- 노트
- 고급 통계 및 개별 평가 이력 상세 조회
- 운영체제 알림, 앱 종료 후 알림 및 푸시 알림
- 문제집 삭제
- 이미지 업로드 및 파일 관리
- 문제집 전체를 대상으로 하는 통합 검색
- 태그
- 카테고리
- 사용자 관리
- 로그인
- API 설계
- DB 설계
- 기술 스택 설계
- 고급 복습 알고리즘
- 학습 기록 상세 분석
- 학습 세션 진행 위치 복원
- 데이터 내보내기/가져오기 및 기기 간 동기화

## 13. MVP 완료 기준

다음 흐름이 정상적으로 동작하면 1차 MVP가 완료된 것으로 본다.

```text
1. 문제집 목록을 확인한다.
2. 문제집을 선택한다.
3. 문제집 상세에서 암기 레벨별 카드 현황을 확인한다.
4. 학습하기 버튼을 누른다.
5. 문제가 한 장씩 표시된다.
6. 정답 확인 버튼을 누른다.
7. 정답과 해설을 확인한다.
8. 몰라요 또는 알아요를 선택한다.
9. 다음 문제로 이동한다.
10. 마지막 문제까지 반복한다.
```

## 14. 현재 구현 현황

### 14.1 실행 환경과 초기 데이터

- 별도 빌드나 서버 설치 없이 `prototype/index.html`을 브라우저에서 열어 실행합니다.
- HTML, CSS, 일반 JavaScript로 구성된 프로토타입이며 서버 API나 DB는 없습니다.
- 최초 실행 시 Spring Security 5장, 회로이론 3장, 컴퓨터 네트워크 4장으로 총 3개 문제집과 12장의 예시 카드를 제공합니다.
- 생성한 문제집·문제와 학습 결과는 예시 데이터에 함께 반영됩니다.
- 디자인의 색상, 레이아웃, 컴포넌트와 반응형 기준은 [DESIGN.md](../DESIGN.md)를 따릅니다. 해당 문서의 추가 개선 지침은 모두 구현 완료된 사항을 의미하지 않습니다.

### 14.2 화면과 이동 경로

| 화면 | 해시 경로 | 구현 내용 |
| --- | --- | --- |
| 문제집 목록 | `#books` | 전체 문제집, 카드 수, 오늘 학습 수, 평균 레벨, 최근 학습일, 생성 진입 |
| 문제집 상세 | `#book/{id}` | 레벨 1~5 분포, 학습 시작, 문제 생성 진입 |
| 학습 | `#study/{id}` | 질문, 정답·해설, 자기 평가, 진행률, 완료 결과 |
| 문제집 만들기 | `#new-book` | 이름과 소개를 입력해 빈 문제집 생성 |
| 문제집 수정 | `#edit-book/{id}` | 기존 제목과 한 줄 소개 수정 |
| 문제 만들기 | `#create/{id}` | 선택한 문제집에 세 가지 유형의 카드 추가 |
| 문제 관리 | `#manage/{id}` | 등록 문제 검색·레벨 필터·페이징, 수정, 삭제, 개별 레벨 초기화 |
| 문제 수정 | `#edit/{id}/{cardId}` | 기존 내용을 불러와 수정, 학습 진입 시 경로 끝에 `/study` 사용 |
| 설정 | `#settings` | 단축키, 알림 시각, 문제 제한시간 설정 |
| 학습 통계 | `#stats` | 요약 수치, 최근 7일 그래프, 문제집별 표 |

존재하지 않는 문제집이나 알 수 없는 경로는 목록으로 돌아갑니다. 학습 세션 없이 학습 경로를 직접 열면 해당 문제집 상세를 표시합니다. 새로고침으로 진행 중인 세션 위치를 복원하지는 않습니다.

### 14.3 문제집 생성

- 목록의 `문제집 만들기`에서 이름과 한 줄 소개를 입력합니다.
- 이름은 앞뒤 공백을 제거한 뒤 1~60자로 입력해야 합니다. 소개는 선택 사항이며 최대 160자입니다.
- 저장 성공 시 생성한 문제집 상세로 이동합니다.
- 빈 문제집은 카드 수 0장, 평균 레벨 0.0으로 표시하며 학습 시작 대신 `첫 문제 만들기`를 안내합니다.
- 저장 실패 시 생성 시도를 되돌리고 오류를 표시합니다.
- 문제집 이름의 중복 제한과 문제집 삭제는 없습니다. 기존 문제집의 제목·소개 수정은 14.13절을 따릅니다.

### 14.4 문제 등록

| 항목 | 구현 내용 |
| --- | --- |
| 유형 | 질문 & 답변, 빈칸 채우기, 선다형 |
| 문제 | 필수, 입력 폼 최대 2,000자 |
| 정답 | 질문형·빈칸형에서 필수, 입력 폼 최대 2,000자 |
| 빈칸 표시 | 문제에 연속된 밑줄 두 개 이상(`__`) 포함 필요 |
| 선다형 보기 | 서로 다른 보기 4개 필수, 각 입력 폼 최대 300자 |
| 선다형 정답 | 보기 중 하나 선택, 선택한 보기 문구를 정답으로 저장 |
| 해설 | 선택 사항, 입력 폼 최대 3,000자 |
| 최초 암기 레벨 | Level 1 |

- 유형에 따라 정답 입력란 또는 보기 입력란을 전환합니다.
- 저장 성공 시 문제집 상세로 이동하고 새 문제 저장 안내를 표시합니다.
- 문제 추가 시 해당 문제집의 당일 완료 상태를 해제합니다. 현재 규칙에서는 새 카드만이 아니라 문제집 전체 카드가 다시 오늘 학습 대상으로 표시됩니다.
- 저장 실패 시 카드 추가와 완료 상태 변경을 되돌리고 입력 내용을 유지합니다.
- 사용자 입력을 화면에 출력할 때 HTML 특수 문자를 이스케이프합니다.
- 이미지 입력·업로드는 없습니다. 현재 문제 이미지 표시는 예시 회로 문제의 내장 SVG에 한정됩니다.

### 14.5 학습 진행과 암기 레벨

1. 문제집의 모든 카드를 저장된 순서대로 학습합니다. 카드 섞기나 레벨별 선별은 없습니다.
2. 질문형·빈칸형은 답을 생각한 뒤 정답을 확인합니다. 학습 중 텍스트 답안을 입력하거나 자동 채점하지 않습니다.
3. 선다형은 보기를 선택할 수 있습니다. 정답 공개 후 정답 보기를 표시하고 선택 변경을 막습니다. 보기를 선택하지 않아도 정답을 확인할 수 있습니다.
4. 정답과 해설은 같은 화면에서 공개됩니다. 해설이 없으면 등록된 해설이 없다는 안내를 표시합니다.
5. `알아요`는 레벨을 1 올리고, `몰라요`는 1 내립니다. 레벨 범위는 1~5입니다.
6. 평가는 보기 선택의 정오와 별개인 자기 평가입니다. 평가할 때마다 이력과 최근 학습일을 기록하고 다음 카드로 이동합니다.
7. 마지막 카드 평가 후 당일 완료로 기록하고, 해당 세션의 `알아요`·`몰라요` 수와 상세 이동 버튼을 표시합니다.

**오늘 학습 수의 현재 계산 규칙:** 문제집을 오늘 완료했으면 0장, 완료하지 않았으면 전체 카드 수입니다. 부분 진행에 따라 남은 카드 수를 차감하거나 카드별 복습일을 계산하지 않습니다. 당일 완료 후에도 `한 번 더 학습하기`로 전체 카드를 다시 학습할 수 있습니다. 날짜는 기기의 현지 날짜를 기준으로 합니다.

초기 기획의 “가까운 시일 내 다시 학습”이나 “복습 간격 증가”는 방향성입니다. 현재 구현은 레벨 증감과 당일 완료 표시까지이며 간격 반복 스케줄러는 없습니다.

### 14.6 설정과 단축키

| 설정 | 기본값 | 동작 |
| --- | --- | --- |
| 단축키 사용 | 켜짐 | 학습 화면에서만 동작 |
| 정답 확인 | `Space` | 정답 공개 |
| 몰라요 | `1` | 정답 공개 후 자기 평가 |
| 알아요 | `2` | 정답 공개 후 자기 평가 |
| 학습 알림 | 꺼짐 | 앱 내 알림 활성화 여부 |
| 알림 시각 | `20:00` | 기기 현지 시각 기준 |
| 문제 제한시간 | 0초 | 0은 무제한, 최대 600초 |

- 단축키 후보는 `Space`, `Enter`, `1`, `2`, `3`, `a`, `s`, `d`, `j`, `k`, `l`입니다. 세 동작에 서로 다른 키를 지정해야 합니다.
- 입력란 편집 중, 한글 조합 중, 키 반복 및 보조키 조합에서는 학습 단축키를 실행하지 않습니다.
- 제한시간은 0~600 사이 정수만 허용합니다. 새 문제의 제한시간은 해당 문제를 시작할 때 정합니다.
- 남은 시간을 표시하고 시간이 끝나면 정답만 공개합니다. 자동으로 `몰라요` 처리하거나 다음 문제로 이동하지 않습니다.
- `기본값으로 설정`은 폼에 기본값을 불러옵니다. `설정 저장하기`를 눌러야 적용·저장됩니다.
- 저장 실패 시 이전 설정으로 되돌리고 오류를 표시합니다.

### 14.7 앱 내 학습 알림

- 활성화된 상태에서 지정 시각 이후가 되면 하루 한 번 앱 하단에 알림을 표시합니다. 지정 시각 이후 앱을 열어도 확인합니다.
- 알림에는 문제집 목록 이동과 닫기 기능을 제공합니다.
- 앱 시작 시 및 이후 10초 간격으로 시각을 확인합니다. 정확한 시각 실행을 보장하지 않으며 백그라운드 탭에서는 지연될 수 있습니다.
- 알림을 표시한 날짜를 로컬에 저장합니다. 저장에 실패하면 다음 실행에서 중복 표시될 수 있습니다.
- 앱이 열려 있어야 하며 운영체제 알림, 푸시, 앱 종료 후 알림은 지원하지 않습니다.

### 14.8 학습 통계

- 요약: 오늘 평가 횟수, 누적 평가 횟수, 전체 평가 중 `알아요` 비율, 평가한 날짜의 수를 표시합니다.
- 최근 7일: 오늘을 포함한 날짜별 평가 횟수를 막대그래프와 수치로 표시합니다.
- 문제집별: 카드 수, 평가 횟수, `알아요` 비율, 평균 레벨을 표로 표시합니다.
- 같은 카드를 반복 평가해도 매번 횟수에 포함됩니다. 문제를 열거나 정답만 공개하는 것은 평가 횟수에 포함되지 않습니다.
- `알아요` 비율은 자기 평가 비율이며 선다형 정답률이 아닙니다. 학습한 날 수는 서로 다른 평가 날짜 수이며 연속 학습일이 아닙니다.
- 전체 평가가 없으면 요약 비율은 0%로 표시합니다. 문제집별 평가 이력이 없으면 비율은 `—`, 카드가 없으면 평균 레벨은 `—`로 표시합니다.
- 통계 기능 도입 전 기록을 소급 생성하지 않습니다. 현재 저장 이력에는 문제집 ID, 날짜, 자기 평가 결과만 있으며 카드별 이력이나 소요 시간 분석은 없습니다.

### 14.9 저장과 복원

- 저장소는 현재 브라우저의 `localStorage`이며 키는 `chagok-study-preview-v1`입니다.
- 사용자 문제집 정보, 추가한 카드, 카드별 레벨, 최근 학습일, 당일 완료 상태, 설정, 평가 이력, 마지막 알림 날짜를 저장합니다.
- 문제 관리 기능부터는 예시 문제를 포함한 전체 카드 목록과 고유 ID를 저장합니다. 이전 `customCards`·`levels` 형식도 읽어 다음 저장 시 새 형식으로 전환하며, 예시 문제의 수정·삭제도 재실행 후 유지합니다.
- 앱을 다시 열면 예시 데이터와 저장 데이터를 합쳐 복원합니다. 진행 중인 문제 번호, 선택한 보기, 제한시간은 복원하지 않습니다.
- 읽기 실패나 JSON 파싱 실패 시 빈 저장 데이터로 시작하며, 복원 시 일부 필드의 형식과 범위를 검사합니다. 모든 손상 데이터를 복구하는 기능은 아닙니다.
- 문제집 생성·수정, 문제 생성·수정·삭제·레벨 초기화 및 설정 변경은 저장 실패 시 변경을 되돌립니다. 학습 평가는 저장에 실패해도 현재 메모리에 반영하고 계속 진행하며 완료 화면에서 저장 제한을 안내합니다.
- 로그인, 서버 백업, 기기 간 동기화는 없습니다. 브라우저 저장 데이터를 삭제하면 사용자 데이터와 학습 기록이 사라집니다.

### 14.10 화면 및 접근성 구현

- 녹색 강조색과 카드·패널 중심의 공통 디자인을 사용합니다.
- 작은 화면에서는 사이드바를 상단 탐색으로 전환하고 문제집 목록은 3열에서 2열, 1열로 변경합니다. 통계 표는 영역 내부 가로 스크롤을 지원합니다.
- 입력 레이블, 일부 도움말 연결, 오류·상태 알림 역할, 현재 메뉴 표시, 학습 진행률 접근성 속성을 적용했습니다.
- 경로 전환과 학습 평가 후 본문으로 포커스를 이동합니다.
- 전체 접근성 준수나 모든 브라우저에서의 시각 검증을 완료했다는 의미는 아닙니다. 대비, 터치 영역, 모션 감소 등 추가 기준은 디자인 지침에 따라 확인해야 합니다.

저장소 루트에서 다음 명령으로 기존 동작 검증을 실행합니다. 검증 스크립트는 현재 작업 디렉터리를 기준으로 소스 파일을 읽으므로 `prototype`으로 이동해야 합니다.

```powershell
Set-Location prototype
node verify.cjs
```

기존 검증 스크립트는 브라우저 의존 부분을 대체하여 다음 항목을 확인합니다.

- 문제집 생성, 빈 문제집 표시 및 학습 시작 방지
- 세 가지 유형의 카드 생성과 저장 데이터 복원
- 사용자 입력의 HTML 이스케이프와 중복 단축키 거부
- 제한시간 종료 시 정답 공개 및 평가 전 이력 미생성
- 자기 평가 후 다음 카드 이동, 레벨과 통계 반영 및 복원
- 알림 표시 날짜 기록과 주요 경로 렌더링
- 문제집·문제·설정 저장 실패 시 변경 취소
- 이전 저장 형식 호환, 예시 문제 수정·삭제와 빈 목록의 영구 저장
- 학습 중 수정 후 진행 위치 유지, 개별 레벨 초기화 시 이력 유지
- 수정 검증 실패, 삭제 취소, 수정·삭제·초기화 저장 실패 시 복구
- 예시·사용자 문제집 제목·소개 수정 및 복원, 입력 검증, 저장 실패 시 복구
- 검색과 레벨 필터 조합, 페이지 분할·범위 보정, 상세의 레벨별 이동 링크

이 검증은 실제 브라우저의 화면 배치, 키보드 이벤트 전체 흐름, 백그라운드 타이머, 모든 입력 경계값을 검증하지 않습니다. UI 변경 시에는 주요 화면과 모바일 배치, 포커스 이동, 실제 저장·재실행 동작을 별도로 확인합니다.

### 14.12 문제 관리 및 학습 중 수정

- 문제집 상세의 `문제 관리`에서 등록된 문제를 순서대로 표시합니다. 각 항목은 문제 유형, 질문, 현재 암기 레벨, 펼쳐 볼 수 있는 정답·해설을 제공합니다.
- 관리 화면에서 문제 생성, 수정, 삭제, 개별 암기 레벨 초기화가 가능합니다. 문제 전체를 삭제해도 빈 목록을 저장하고 첫 문제 생성을 안내합니다.
- 수정 폼은 기존 유형·질문·정답·보기·해설을 채워 표시하며 생성과 같은 입력 검증을 적용합니다. 유형 변경을 지원하고 기존 회로 이미지는 유지합니다.
- 수정 시 카드 ID와 암기 레벨, 이전 평가 이력은 유지하고 당일 완료 표시를 해제합니다.
- 삭제는 사용자 확인 후 실행하며 이전 학습 통계를 삭제하지 않습니다. 삭제된 문제는 복구 기능이 없습니다.
- 학습 중에는 정답 확인 전후 모두 현재 문제의 `문제 수정`과 `암기 레벨 초기화`를 제공합니다.
- 수정 화면에서는 제한시간을 일시 정지합니다. 취소하면 같은 문제의 선택·정답 공개 상태와 남은 시간으로 돌아갑니다. 저장하면 세션 진행 위치와 이전 평가 횟수를 유지하면서 현재 문제의 정답을 숨기고 선택을 해제해 새 제한시간으로 시작합니다.
- 암기 레벨 초기화는 해당 문제만 Level 1로 바꾸고 당일 완료 표시를 해제합니다. 평가 이력을 추가·삭제하거나 다음 문제로 이동하지 않습니다. 이미 Level 1이면 버튼을 비활성화합니다.
- 수정·삭제·초기화 저장이 실패하면 데이터와 당일 완료 상태를 복구하고 오류를 표시합니다. 수정 실패 시 작성 중인 입력도 유지합니다.

### 14.13 문제집 수정과 레벨별 조회

- 문제집 상세의 `문제집 수정`에서 제목과 한 줄 소개를 수정합니다. 예시 문제집과 직접 만든 문제집 모두 지원합니다.
- 제목은 앞뒤 공백 제거 후 1~60자 필수이며, 한 줄 소개는 최대 160자 선택 입력입니다. 소개를 비워 저장할 수 있습니다.
- 저장 후 상세로 돌아가며 목록·상세·이동 경로·통계에 수정된 이름이 반영됩니다. 카드, 암기 레벨, 학습 이력은 유지합니다.
- 저장 실패 시 기존 제목·소개로 복구하고 작성 중인 입력과 오류 안내를 유지합니다.
- 상세의 소개에는 입력한 소개만 표시하며 “얼마나 기억하고 있는지 확인해 보세요.” 고정 문구는 제거했습니다.
- 상세의 Level 1~5 행은 클릭 가능한 링크입니다. 선택 시 `#manage/{id}?level={1~5}`로 이동해 해당 레벨의 카드만 표시합니다. 카드가 없는 레벨도 선택할 수 있으며 빈 결과를 안내합니다.

### 14.14 문제 검색과 페이징

- 선택한 문제집 안에서 질문·정답·해설·선다형 보기의 부분 문자열을 검색합니다. 검색어의 앞뒤 공백과 영문 대소문자를 구분하지 않습니다.
- 검색어는 최대 200자이며 검색 버튼 또는 Enter로 적용합니다. 암기 레벨 선택을 함께 적용할 수 있습니다.
- 검색·레벨 조건을 먼저 적용하고 저장된 순서대로 페이지당 10장씩 표시합니다. 결과 수와 현재 표시 범위, 현재/전체 페이지, 이전·다음 이동을 제공합니다.
- 검색 조건 변경 시 1페이지부터 표시합니다. 조건 초기화는 검색어와 레벨 필터를 모두 해제합니다.
- `q`, `level`, `page`를 해시 경로의 쿼리로 기록해 새로고침과 브라우저 뒤로/앞으로 이동에 반영합니다. 같은 실행 중 수정 화면에서 돌아오면 이전 검색·레벨·페이지를 유지합니다.
- 삭제·레벨 변경으로 현재 페이지의 카드가 사라지면 남아 있는 유효 페이지로 보정합니다. 검색 결과 없음과 문제집 자체가 빈 상태를 구분해서 안내합니다.
